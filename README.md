# Tactical Optimizer

**Tactical Optimizer** is een no-nonsense optimalisatietool voor Windows, geleverd als een handige, standalone executable (`.exe`). 
Ontwikkeld om je pc in topconditie te houden, werkt de tool snel, doelgericht en diepgaand om je systeem te ontdoen van onnodige ballast en privacy-inbreuken.


<img width="847" height="728" alt="868e5dcf-f74d-4a1c-8f76-dd866bfc5f5d" src="https://github.com/user-attachments/assets/0eaa23fe-6fb4-4a2a-8f63-003bf04cf19d" />


  ## 🛠️ Wat doet het?

* **Standalone Executable:** Direct uit te voeren als `.exe` zonder installatie of ingewikkelde setup.
* **Grondig Opschonen:** Verwijdert veilig tijdelijke bestanden, systeemcaches, update-restanten en hardnekkige logboeken.
* **Privacy & Telemetrie:** Schermt ongewenste gegevensverzameling af en schakelt onnodige achtergrondtracking van Windows uit.
* **Licht & Direct:** Geen zware software op de achtergrond; het script voert direct uit wat nodig is en sluit weer af.

---

## 📋 Belangrijkste Functionaliteiten

| Categorie | Wat wordt er aangepakt? |
| :--- | :--- |
| **Schoonmaak** | Tijdelijke bestanden (`Temp`, `%TEMP%`), browsercaches en achtergebleven logbestanden die je schijfruimte vervuilen. |
| **Privacy** | Beperken van telemetrie, diagnostische gegevens en ongewenste achtergrondrapportages aan Microsoft. |
| **Systeemprestaties** | Optimaliseren van verborgen instellingen voor een vlottere en responsievere Windows-ervaring. |

---

## Hoe te gebruiken?

1. Ga naar de **Releases**-pagina aan de rechterkant van dit project.
2. Download de meest recente `Tactical-Optimizer.exe`.
3. Klik met de rechtermuisknop op het bestand en kies **Als administrator uitvoeren** (dit is vereist om alle systeembestanden te kunnen bereiken).
4. Volg de stappen op het scherm en geniet van een schone, snelle pc!

## ⚠️ Belangrijke Disclaimer & SmartScreen Waarschuwing

Omdat deze tool eigenhandig is ontwikkeld en niet is voorzien van een dure commerciële digitale handtekening, kan Windows of je antivirussoftware ingrijpen bij de eerste start:

* **Windows SmartScreen:** Kan een melding geven met *"Windows heeft beveiligd"*. Klik op **Meer informatie** en vervolgens op **Toch uitvoeren**.
* **Antivirus:** Sommige strikte virusscanners kunnen een heuristische melding geven omdat het een onbekende `.exe` betreft. Dit is een bekend fenomeen bij zelfgemaakte scripts en tools; de code is volledig veilig en open voor controle.
