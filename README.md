# 🚀 Tactical Optimizer

**Tactical Optimizer** is een no-nonsense optimalisatietool voor Windows, geleverd als een handige, standalone executable (`.exe`). Ontwikkeld om je pc in topconditie te houden, werkt de tool snel, doelgericht en diepgaand om je systeem te ontdoen van onnodige ballast.

## 🛠️ Wat doet het?
* **Standalone Executable:** Direct uit te voeren als `.exe` zonder installatie.
* **Grondig Opschonen:** Verwijdert veilig tijdelijke bestanden, caches en hardnekkige logboeken.
* **Privacy & Telemetrie:** Schermt ongewenste gegevensverzameling af.
* **Licht & Direct:** Geen zware achtergrondprocessen.

---
*⚠️ **Let op:** Omdat dit een eigenbouw-tool is zonder dure digitale handtekening, kan Windows SmartScreen of je antivirus de `.exe` in eerste instantie blokkeren ("Onbekende uitgever"). Dit is normaal; je kunt kiezen voor "Meer informatie" -> "Toch uitvoeren".*
